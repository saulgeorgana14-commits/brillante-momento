# Brillante Momento

> Experiencias de Picnic de Lujo en Paraíso y Comalcalco, Tabasco.

Este repositorio contiene la landing page oficial de **Brillante Momento**, diseñada para ser una máquina de conversión rápida y optimizada para dispositivos móviles.

## Características

- **Diseño Premium:** Estilo *Liquid Glass* (Crema, Terracota y Dorado) con sombras suaves, efectos de desenfoque y animaciones fluidas.
- **Cotizador Interactivo:** El formulario calcula y resume el precio y descripción del paquete elegido en tiempo real.
- **Integración con WhatsApp:** Envío de reservas y cotizaciones directamente a la cuenta oficial de WhatsApp.
- **Optimización Mobile:** Carga súper rápida, sin dependencias pesadas y con botones táctiles diseñados bajo estándares de accesibilidad (UI/UX Pro Max).

## Estructura del Proyecto

- `index.html`: Redirección automática de entrada.
- `brillante_momento_inicio_es/`:
  - `code.html`: Código fuente HTML/CSS (Tailwind CSS CDN).
  - `screen.png`: Captura de pantalla de previsualización.
- `Catalogo brillante momento.pdf.pdf`: Catálogo original en PDF.
